# Yazan Website

A personal portfolio website showcasing various interests and projects.

## Features

- **Home Page** (`index.html`) - Main landing page
- **Gaming Section** (`gaming.html`) - Gaming-related content
- **Guitar Section** (`guitar.html`) - Music and guitar content
- **Design Section** (`design.html`) - Design projects and work
- **Clips Section** (`clips.html`) - Video clips and media content

## Technologies Used

- HTML5
- CSS3
- JavaScript

## File Structure

```
yazanwebsite/
├── index.html      # Main homepage
├── gaming.html     # Gaming section
├── guitar.html     # Guitar/music section
├── design.html     # Design section
├── clips.html      # Clips/media section
├── style.css       # Main stylesheet
├── script.js       # JavaScript functionality
└── README.md       # This file
```

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/alikizzeldin/yazanweb.git
   ```

2. Open `index.html` in your web browser to view the website.
